### Our development environment

We'll continue with the technologies used in our learning project:

- Java: Java 17+
- JSP: Jakarta Server Pages
- Servlet container: Apache Tomcat 10.1
- Frontend: React
- Database: PostgreSQL
- API testing: Postman
- IDE: IntelliJ IDEA

One important distinction: JSP is primarily a server-side view technology. In our React-based application, we'll learn JSP independently and understand how it fits into traditional Java web applications and how it compares with our React frontend.
