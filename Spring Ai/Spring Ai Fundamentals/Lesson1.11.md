# 🚀 1.11 — Mini Project: AI Chat REST API

# 1. Create the Spring Boot Project

Create a Spring Boot project with:

```text
Java
Spring Web
Spring AI Google GenAI
```

For the current Spring AI Google GenAI integration, Spring AI provides a Google GenAI chat starter and supports Gemini through the Gemini Developer API. ([Home][1])

Your dependency should follow the starter appropriate to the Spring AI version you're using.

For example:

```xml
<dependency>
    <groupId>org.springframework.ai</groupId>
    <artifactId>spring-ai-starter-model-google-genai</artifactId>
</dependency>
```

**Important:** Spring AI has been evolving quickly, so don't mix dependency/API examples from different Spring AI generations. The current documentation confirms the Google GenAI integration and current API structure. ([Home][1])

In `application.properties`:

```properties
spring.ai.google.genai.api-key=${GOOGLE_API_KEY}

```

And configure:

```text
GOOGLE_API_KEY
```

as an environment variable.

# 3. Create the Controller

Now our main class.

```java
package com.example.aichat.controller;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.web.bind.annotation.*;
import reactor.core.publisher.Flux;

@RestController
@RequestMapping("/api/chat")
public class ChatController {

    private final ChatClient chatClient;

    public ChatController(ChatClient.Builder chatClientBuilder) {
        this.chatClient = chatClientBuilder.build();
    }

    @PostMapping
    public String chat(@RequestBody ChatRequest request) {

        String response = chatClient
                .prompt()
                .system("""
                        You are a helpful AI assistant.

                        Give clear and accurate answers.
                        Explain technical concepts simply.
                        Use examples when useful.
                        """)
                .user(request.message())
                .call()
                .content();

        return response;
    }

    @GetMapping("/stream")
    public Flux<String> stream(@RequestParam String message) {

        return chatClient
                .prompt()
                .system("""
                        You are a helpful AI assistant.

                        Give clear and accurate answers.
                        Explain technical concepts simply.
                        """)
                .user(message)
                .stream()
                .content();
    }

    public record ChatRequest(String message) {
    }
}
```

# 4. Understand the Normal Endpoint

Look carefully at:

```java
@PostMapping
public String chat(@RequestBody ChatRequest request)
```

The client sends:

```json
{
    "message": "What is Spring AI?"
}
```

Spring converts that JSON into:

```java
ChatRequest request
```

Then:

```java
request.message()
```

gives:

```text
What is Spring AI?
```

# 5. The Spring AI Part

This is the important part:

```java
String response = chatClient
        .prompt()
        .system("""
                You are a helpful AI assistant.
                Give clear and accurate answers.
                Explain technical concepts simply.
                """)
        .user(request.message())
        .call()
        .content();
```

Let's break it down:

```text
prompt()
   ↓
Start prompt

system()
   ↓
Define AI behavior

user()
   ↓
User's actual question

call()
   ↓
Send request to Gemini

content()
   ↓
Extract generated text
```

You've now used **1.5 → 1.6 → 1.8 → 1.9** together.

# 7. Add Prompt Template

Let's improve our application.

Instead of hardcoding:

```java
.user(request.message())
```

we can construct a reusable prompt.

For example:

```java
String prompt = """
        Explain the following topic as a Java teacher.

        Topic:
        {topic}

        Requirements:
        - Use simple language.
        - Give one practical example.
        - Keep the answer concise.
        """.replace("{topic}", request.message());
```

Then:

```java
String response = chatClient
        .prompt()
        .user(prompt)
        .call()
        .content();
```

However, for a real Spring AI application, use Spring AI's prompt-template facilities rather than treating `.replace()` as your template engine. Spring AI's `PromptTemplate` uses variables and a configurable `TemplateRenderer`. ([Home][2])

We'll make prompt templates much more sophisticated in **Phase 2**.

Now the interesting part:


Notice:


became:

```java
.stream()
```

and:

```java
String
```

```java
Flux<String>
```

So:

```text
Normal
------
call()
 ↓
String


Streaming
---------
stream()
 ↓
Flux<String>
```

Spring AI's current chat API supports streaming responses through the reactive `Flux` model. ([Home][1])

# 9. Complete Project

Here is the complete controller again so you have one clean version to work with:

```java
package com.example.aichat.controller;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.web.bind.annotation.*;
import reactor.core.publisher.Flux;

@RestController
@RequestMapping("/api/chat")
public class ChatController {

    private final ChatClient chatClient;

    public ChatController(ChatClient.Builder chatClientBuilder) {
        this.chatClient = chatClientBuilder.build();
    }

    // Normal AI response
    @PostMapping
    public String chat(@RequestBody ChatRequest request) {

        try {

            String response = chatClient
                    .prompt()
                    .system("""
                            You are a helpful AI assistant.

                            Give clear and accurate answers.
                            Explain technical concepts simply.
                            Use examples when useful.
                            """)
                    .user(request.message())
                    .call()
                    .content();

            if (response == null || response.isBlank()) {
                return "No response was generated.";
            }

            return response;

        } catch (Exception e) {
            return "Unable to generate AI response.";
        }
    }

    // Streaming AI response
    @GetMapping("/stream")
    public Flux<String> stream(@RequestParam String message) {

        return chatClient
                .prompt()
                .system("""
                        You are a helpful AI assistant.

                        Give clear and accurate answers.
                        Explain technical concepts simply.
                        """)
                .user(message)
                .stream()
                .content();
    }

    public record ChatRequest(String message) {
    }
}
```
