# Topic 2.14 — Structured Output + Prompt Engineering

Now let's connect two important skills: telling AI what to produce and controlling the structure of its response. This is especially useful for your AI Skill and Career Management Platform.

## 1. Why combine them?

Imagine a student enters:

* Skills: Java, SQL

* Experience: Beginner

* Goal: Backend Developer

* Test score: 65

You want AI to identify skill gaps and return data your Spring Boot backend can process reliably.

Prompt engineering and structured output solve different problems:

Prompt engineering — controls the meaning

Tells AI its role, task, context, priorities, and constraints.

Example: “Identify exactly three important technical skill gaps for a beginner backend developer.”

Structured output — controls the data shape

Defines the expected fields and data types so the response can be converted into a Java object.

Example: `careerGoal` as a String, `score` as an integer, and `skillGaps` as a list.

The key idea: a well-structured response can still contain poor recommendations, while a good prompt can still produce incorrectly formatted data. Use both.

## 2. Build the example step by step

### Step 1: Define the Java record

Java

```
import java.util.List;

public record StudentEvaluation(
    String careerGoal,
    int score,
    List<String> skillGaps,
    String recommendation
) {}
```

This defines the shape of the data your application expects.

### Step 2: Design a strong prompt

For example:

```
Role:
You are an experienced backend career advisor.

Student information:
Skills: {skills}
Experience: {experience}
Career goal: {goal}
Test score: {testScore}

Task:
Evaluate the student's readiness for the target career.

Constraints:
- Identify exactly 3 relevant technical skill gaps.
- Prioritize gaps based on career relevance.
- Keep the recommendation concise.
- Base recommendations on the provided information.
- Do not invent qualifications or experience.

Return the evaluation using the required structured format.
```

Notice how the prompt guides the quality and relevance of the answer, while the record defines the data structure.

### Step 3: Ask Spring AI to return the Java object

Assuming `chatClient` is already configured in your Spring Boot application:

Java

```
StudentEvaluation evaluation = chatClient.prompt()
    .user("""
        You are an experienced backend career advisor.

        Student skills: Java, SQL
        Experience: Beginner
        Career goal: Backend Developer
        Test score: 65

        Identify exactly 3 relevant technical skill gaps.
        Prioritize the most important gaps.
        Give a concise recommendation.
        """)
    .call()
    .entity(StudentEvaluation.class);
```

Spring AI attempts to convert the model response into a `StudentEvaluation` object.

You can then access the fields:

Java

```
System.out.println(evaluation.careerGoal());
System.out.println(evaluation.score());
System.out.println(evaluation.skillGaps());
System.out.println(evaluation.recommendation());
```

Note: This example demonstrates the general `.entity()` workflow. Exact structured-output configuration and guarantees depend on your Spring AI version and model provider.

## 3. What does this look like in a real application?

React frontend

Student submits skills and career goal

Spring Boot + Spring AI

Prompt engineering + structured output

Java `StudentEvaluation` object

Convert response and validate fields and business rules

PostgreSQL + React

Persist the evaluation and display recommendations

Before saving an evaluation, your backend should still check rules such as whether the score is within `0–100` and exactly three skill gaps were returned. Also remember that a score generated by AI is an estimate, not automatically an objective measurement of a student's ability.
