# Phase 2 Completion Criteria

I should be able to:

1. Design a good AI prompt.
2. Explain why a prompt works or fails.
3. Use zero-shot and few-shot prompting.
4. Create reusable prompt templates.
5. Protect prompts against basic prompt-injection problems.
6. Design Java DTOs/records for AI responses.
7. Convert AI responses into Java objects using Spring AI.
8. Validate structured AI responses.
9. Use structured output for my student evaluation feature.
10. Use structured output for my career-roadmap feature.
